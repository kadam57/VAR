## Overview
This repository contains the empirical code and research paper investigating macroeconomic shock transmission and real output connectedness between systemic global drivers (**United States, China, Germany**) and the **Visegrád Four (Czechia, Hungary, Poland, Slovak Republic)** over the period **1995–2023**.

Using the **Diebold & Yılmaz (2012, 2014)** rolling-window network framework based on **Generalized Forecast Error Variance Decomposition (GFEVD)**, the study maps the directional transmission of growth shocks without relying on arbitrary variable ordering.
